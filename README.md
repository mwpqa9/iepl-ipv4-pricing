## 先搞清楚：IEPL 独立 IPv4 到底指什么

这两个词拆开看更好理解。

**IEPL/IPLC** 是点对点的内网级传输线路。你的流量从国内入口进去后走专有通道到海外出口，不经过公共互联网，所以晚高峰拥堵、绕路丢包这些公网 VPS 的常见病，理论上和它无关。Mkcloud 官方给出的端内参考延迟是：广港、厦港、泉港 1~2ms，沪港 21ms，沪日 25~28ms，沪美 124~134ms。注意这些是线路内部的延迟，不是你家到目标网站的全程延迟。

**独立 IPv4** 在 Mkcloud 这里的交付方式是「单端双独立 IP」：每台专线 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP。你从入口连上去，VPS 里跑的浏览器、业务软件自动从出口 IP 对外访问。两个 IP 都是独享的，不存在和别人共用一个出口 IP 的问题——这正是做多账号运营的人在意的地方。

官方知识库里「一店一 IP、环境隔离」的说法，指的就是这个用法。

## 双端独立 IP 的实际体验和三个限制

买之前有几条官方明示的规则，比价格更值得看：

- **出口不接受外部连入。** 出口 IP 只负责向外访问，不能用来对外提供建站、邮件接收、支付回调这类需要公网入站的服务。想拿它做公开网站的人可以直接划走了。
- **省级白名单。** 为防止机场类滥用，所有专线产品只允许绑定省份内的 IP 连入，开通时选一次，之后可以自己改绑其他省份。
- **官方明确不保证账号不关联。** 知识库原话是「独立 VPS 和独享 IP 不保证账号不关联或通过平台审核」。IP 独享只是隔离的第一步，浏览器指纹、账号资料这些还得自己管。

另外两条购买规则：流量按上行加下行双向统计；退款仅支持质量问题，而且需要你拿出具体延迟、速度数据，开通后不支持更换地域。月付/季付/半年/年付到三年付都可以选，主流 Linux 发行版系统镜像齐全。

## 四条线怎么选：先看方向，再看延迟

官方知识库有句话说得实在：线路类型不是质量排行榜。选线逻辑其实就两步。

第一步看你的业务目标在哪儿。广港 IEPL 对应香港出口，物理距离最短，适合港区业务和需要香港 IP 的场景；沪日 IPLC 出口日本，25ms 上下的端内延迟做日区业务够用；沪美 IPLC 出口美国，延迟 124~134ms，跑欧美独立站后台、eBay 这类对延迟不敏感但对稳定性敏感的业务是它的定位。人在长三角可以直接用上海电信入口，华南用户选广港更顺。

第二步比单价。同样的 2核4GB/300M 峰值档位，沪港 ¥428 是四条线里最便宜的，广港和沪日 ¥568，沪美 ¥698。如果你的目标出口在香港、人又在长三角，沪港的性价比比广港高；但如果你在广东，广港 1~2ms 的端内延迟体验是沪港给不了的。

流量预算别按单向估。所有套餐流量双向计算，跑爬虫或大文件上传的任务，实际消耗是账面流量的两倍。拿不准就先月付一档试水，官方下单约一分钟自动开通，月付成本可控。

## 适合谁买，谁该绕行

适合的情况很具体：跨境电商多账号需要一店一 IP 做环境隔离、独立站和亚马逊/TikTok 卖家的后台运营、金融量化对港、游戏出海，以及在 VPS 内跑自动化出站任务的团队。这些场景的共同点是——业务程序装在 VPS 里，从出口 IP 主动向外访问。

该绕行的情况同样明确：需要公网入站的（对外建站、邮件服务器、支付回调）、不想做中国身份实名的、期待拿专线当机场用的。最后一种官方直接用省级白名单和技术措施堵死了，不用试。

## 购买流程和开通检查

下单路径不长，但有两个必填项容易漏：

1. 注册后先完成实名：国内手机号 + 身份证号 + 姓名，三者的相关性验证是硬性的，专线产品无一例外。
2. 选线路 → 选网络入口 → 选类型（流量计费或独享带宽）→ 选套餐档位和系统。
3. 在附加选项里**绑定可连入省份**，开通后只有该省份的 IP 能连，选错了后面也能改，但别拖到业务跑起来再改。
4. 购物车填优惠码，确认最终价。支持支付宝付款，周期建议月付起步。
5. 开通后用 SSH 或远程桌面连入口 IP，进 VPS 部署业务程序，出口 IP 自动对外。

再提醒一次退款条款：只有质量问题可退，且要附上具体延迟和速度数据，开通后不能换地域。买之前把自己的用量和方向想清楚，比买完再纠结划算。

## 常见问题

**独立 IPv4 是一个还是两个？**
两个。入口和出口各一个，均为独享，账单里不额外收 IP 费。

**能不能用它建站对外提供服务？**
不能。出口 IP 不接受外部连入，这是产品设计层面决定的，不是限制可选项。

**流量双向计算，1TB 档实际能用多少？**
上下行合计 1TB。纯下载业务约 500GB 下行额度，有上传的任务要相应折减。

**换城市工作了怎么办？**
直连款可以在后台改绑省份，改完用新省份的 IP 连入。IXP 款不限省份，但必须从支持的云厂网络接入。

**独立 IP 能保证我的多个店铺账号不关联？**
官方知识库明确写的是不保证。IP 隔离只是必要条件之一，指纹、Cookie、账号资料这些层面的隔离需要自己配合解决。
